Follow task changes and conversations in one activity timeline, and keep note forms focused on the fields you use.

### Tasks and conversations

- Status, board-column, and description changes appear alongside comments, with timestamps.
- The activity view uses a slim rail, compact change events, and separate comment panels. Post new comments below the history.
- Comments support Markdown, including lists, links, and code blocks. Text direction adjusts automatically for Persian and English.
- **Done** is available as a task status and stays selected after restarting the app. Tasks with this status are excluded from deadline reminders.

### Note templates

- Only fields whose placeholders appear in the note are shown. Notes without template placeholders have no extra inputs.
- Field values stay saved when hidden, so restoring a placeholder restores its input and value.

Existing comments remain available. Activity events begin with this update; earlier task edits cannot be reconstructed.

### Downloads

- Release pages now include direct download buttons for macOS Apple Silicon, Windows 64-bit, and Linux packages, followed by readable changes grouped by feature.
