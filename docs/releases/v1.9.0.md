Copy a note straight into Teams, with its formatting and links intact.

### Notes and sharing

- **Copy Teams** puts formatted text and a plain-text fallback on the clipboard. Paste normally in Teams to keep headings, lists, tables, and clickable links.
- Custom template fields resolve before copying, so shared notes contain the values you entered rather than placeholders.
- The selected LTR or RTL direction is included in the formatted copy.
- If copying fails, the note stays in the editor and you can retry or export it.
