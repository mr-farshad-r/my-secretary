My Secretary 2.1 adds Code Review and automatic saving for task fields, while keeping description edits in drafts until you publish them.

### Task statuses and activity

- Choose Code Review as a task status.
- Add an optional reviewer name for Code Review, or a reason for Pending and Canceled.
- See reviewer names and reasons in the task activity timeline.

### Automatic saving

- Existing task fields save automatically when changed, without confirmation.
- Only description edits are saved as drafts; use Save description to publish them.
- Revert draft restores the description without undoing saved task fields.
- New tasks use Create task to save their initial details.
