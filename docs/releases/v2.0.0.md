My Secretary 2.0 introduces a redesigned workspace inspired by Notion, with a saved Light/Dark appearance choice. Existing local tasks, notes, categories, and activity stay compatible; no data migration is required.

### A redesigned workspace

- Warm paper backgrounds, white cards, thin borders, and blue primary actions in Light mode.
- A matching charcoal palette in Dark mode, with readable status labels, links, and code highlighting.
- Consistent styling across the board, calendar, notes, task editor and activity, settings, categories, archive, and template dialogs.
- Clearer board labels, empty states, date properties, and navigation in smaller desktop windows.

### Choose your appearance

- Select Light or Dark under Settings → Appearance.
- Apply changes immediately and remember the choice after restarting.
- Keep exported notes and copied code suitable for light documents.

### Accessibility and polish

- Visible keyboard focus and associated task field labels.
- Respect the interface animation setting and system reduced-motion preference.
- Preserve Persian text, right-to-left notes, Shamsi deadlines, and Gregorian date labels.
