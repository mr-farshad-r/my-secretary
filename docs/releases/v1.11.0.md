Read code with syntax colors anywhere you preview Markdown, even while offline.

### Markdown code

- Syntax highlighting works in task descriptions, timeline comments, and notes, including inline backticks and fenced code blocks. Specify a language after the opening fence for accurate highlighting; unlabeled code uses automatic detection.
- Highlighted code retains its colors in HTML exports and Teams copies. Highlighting works offline.

Unsupported language labels stay plain text. Use a language label for the most accurate highlighting.
